# 评论分诊：四类整理，只写不发

- **适合**：评论提及一多就漏回，又不想让 Bot 代发或写成统一套话的人
- **详细教程**：[grokguide.si/tutorials/comment-triage](https://grokguide.si/tutorials/comment-triage)
- **思路来源**：[ai_goge 系列 2-5](https://x.com/ai_goge/status/2118869500015841644)。我们**没有**照搬原文指令与截图数字，只保留四类 → 只写不发 → 纠正变规矩 → 每日未回复的闸门。

## 场景

公开评论区漏回；Bot 第一版草稿常是同一个句式；代充、引战回错一句更麻烦。

## 准备

- 已连接 X（能读评论与提及）
- 愿意自己点发送；私信如需整理，PIN 只在审批卡本人填

## 步骤

1. 让 Bot 拉最近 24 小时评论与提及，去掉已回复。
2. 分成要回 / 可回 / 不用回 / 要小心；先给总表再给清单。
3. 只给「要回」写短草稿；禁止点赞、回复、关注、发私信。
4. 若草稿开头统一，指出来并要求记成长期规矩。
5. 建每日未回复例程：清单只进本对话，附原帖链接。

## 提示词

```text
整理最近 24 小时 {{平台}} 上的新评论和提及：
1. 分四类：要回（提问、求助、合作）、可回（夸奖、讨论）、不用回（纯表情、广告）、要小心（负面、争议、质疑价格、代充）；
2. 先给总表，再给「要回」和「要小心」清单（账号、一句话、建议怎么回）；
3. 去掉我已经回过的。
给「要回」写回复草稿：每条不超过 40 字，开头不能重复，不要每条都夸都反问。
只写不发，不要点赞、回复或关注。跳过私信（除非我在审批卡填了 PIN）。
如果这批草稿是同一个句式，按我说的规则重写，并记成长期规矩。
```

## 产出

四类总表 + 要回/要小心清单 + 短草稿（你自己发）+ （可选）每日未回复例程。

## 注意事项

- 要小心默认不回；涉及价格只说官方价并附来源。
- 别一口气连发；隔几分钟更稳。
- 本配方不用真实账号实测；巡检用虚构评论批。

## 小伟点评

本地六事件：四类齐全、已回复剔除、要小心只标记、套话检出、纠正后短草稿多样、全程只写不发；ASSERT_OK。
