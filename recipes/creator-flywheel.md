# 创作者飞轮：手册→选题→教练→先批再剪

- **适合**：做短视频/自媒体，想让 Bot 帮忙但不想被代写、代剪、代发带着跑的人
- **详细教程**：[grokguide.si/tutorials/creator-flywheel](https://grokguide.si/tutorials/creator-flywheel)
- **思路来源**：[XCreators · The ultimate guide to Grok Bot for creators](https://x.com/XCreators/status/2118843705327026400)（@Ethan_Ng_13）。我们**没有**照搬原文步骤表、成片案例与激励计划表述；只保留「手册 → 选题 → 教练 → 先批再剪 → 草稿不代发 → 复盘进 Skill」六闸。

## 场景

一条 60 秒短视频要过选题、脚本、剪辑、分发、复盘。Bot 一上手就写整篇、直接开剪、甚至代发，质量与账号风险都高。

## 准备

- 能给 Bot 看几条自己的成片或喜欢的参考片
- 剪辑工具可选（云电脑 Remotion / 本机剪映等）；本配方不绑定具体软件
- 发布账号的发送权留在自己手里

## 步骤

1. 喂旧作与喜欢的片，让 Bot 整理风格手册（钩子、节奏、语气）；定稿后记长期规矩。
2. 把收藏链接丢给它：每条拆「为什么火 / 钩子 / 节奏 / 声音 / 怎么变成你的」。
3. 自己写草稿，让它当教练：打分、标掉粉点；禁止代写整篇。
4. 上传素材前先要剪辑方案；你点头才开剪。可一次交多条，但每条都要方案闸。
5. 成片后只出多平台文案草稿；发布由你点。把留存掉点写成教训写进 Skill。

## 提示词

```text
你是我的创作搭档，遵守六闸：
1) 先根据我提供的旧作整理风格手册（钩子/节奏/语气），写进长期规矩；不要替我写完整片旁白。
2) 对我丢来的收藏，每条输出：为什么火、钩子、节奏、声音、怎么变成我的。
3) 对我的脚本草稿只打分并列出掉粉点与改法，保留我的语气；禁止代写整篇。
4) 剪辑前先给分镜与节奏方案，等我批准再开剪；未批准不得剪切或配乐。
5) 多平台文案只起草，禁止代发任何平台。
6) 根据留存/互动数据写 1–3 条可复用教训，提议写进创作 Skill，等我确认。
```

## 产出

风格手册 + 选题表 + 脚本教练意见 +（批准后）剪辑方案与成片草稿 + 多平台文案草稿 + 复盘教训。

## 注意事项

- 官方指南里的并行剪辑与跨平台发布能力很强；本站默认**发布与付款始终人点**。
- 一次建太多内容 Bot 容易乱；先手册+教练+剪辑三岗。
- 本配方用虚构作品与脚本做本地巡检，不是真实账号剪辑或代发实测。

## 小伟点评

本地六事件：手册字段齐全、选题五字段、教练不代写且能挑毛病、未批不开剪、分发 sent 空、复盘进 Skill；ASSERT_OK。
