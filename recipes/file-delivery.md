# 交付验收：要能打开、能核对的文件

- **适合**：让 Bot 做表格、报告的人
- **详细教程**：[grokguide.si/tutorials/file-delivery](https://grokguide.si/tutorials/file-delivery)

## 场景

Bot 说做完了，文件却打不开或数字对不上。

## 准备

- 明确的文件格式要求

## 步骤

1. 交任务时就写清格式、文件名和存放位置。
2. 要求附一段核对说明：数据来自哪里、怎么算的。
3. 打开抽查 3 处。

## 提示词

```text
请把结果做成 {{格式，例如 xlsx}}，文件名 {{文件名}}。交付时附三样：文件本身、数据来源列表、一段 5 行以内的核对说明（怎么算的、哪里可能有误差）。交付前你自己先打开检查一遍。
```

## 产出

文件加核对说明。

## 注意事项

- 只说“做个表”容易拿到截图。
- 大文件让它分批交。
