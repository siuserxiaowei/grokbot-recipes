# 总控派活：一张路由表，重活交给工程师 Bot

- **适合**：已经有三五个 Bot、每次都要想“这事该找谁”的人
- **详细教程**：[一个总控派活，专项 Bot 干活](https://grokguide.si/tutorials/fleet-router)
- **思路来源**：[木渡川的 Bot 舰队架构长文](https://x.com/tanglele0318/status/2112069782170173797)、[云启：Grok Bot 当总控、Codex 写代码](https://x.com/lxdiyyy/status/2111066768051761409)

## 步骤

1. 在云电脑建 `/workspace/fleet/routes.json`：每个 Bot 写名字、关键词、共用额度还是独立计费。
2. 总控收到任务先查表派活，并说明派给谁、为什么。
3. “交给 某某：任务”直达；名字不存在就退回问你，不新建 Bot。
4. 写代码、长任务派给独立计费的工程师 Bot，总控只拆活和验收。
5. 结果先回发起人，值得长期留的再交给知识库管家。
