# 两个文件夹快照对比

- **适合**：备份盘、导出目录、前后版本对不上的人
- **详细教程**：[文件夹快照对比](https://grokguide.si/tutorials/folder-snapshot-diff)

## 场景

A 盘和 B 盘「看起来差不多」，不知道谁多了文件、谁改过。

## 步骤

1. 对两个根目录做相对路径 + 大小 + 哈希快照。
2. 输出 only_a / only_b / changed / same。
3. 不自动合并、不删除；差异清单交给你。

## 提示词

```text
对比这两个文件夹，列出只在 A、只在 B、内容变了、完全相同的项。
用相对路径和内容哈希，不要合并或删除任何文件。
A：……  B：……
```

## 产出

四类清单。样例：only_b 1 个新文件，changed 2 个，same 1 个。

## 注意事项

- 大目录先抽样或按子树。
- 符号链接与权限差异可另列，默认比内容。
