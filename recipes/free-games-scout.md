# 免费游戏侦察：只认官方商店

- **适合**：想领限时免费游戏、又不想被转发消息和 Demo 刷屏的人
- **详细教程**：[免费游戏侦察：只认官方商店](https://grokguide.si/tutorials/free-games-scout)

## 场景

“某某游戏限时免费”的消息很多，点进去常常是 Demo 或者已经过期。让 Bot 每周查一次 Epic 的公开促销接口和 GOG 的公开商品目录，把限时免费领取、Demo、本来就免费、预告分开列，截止时间换成你的时区，和上一轮比，只报新出现的。

## 准备

- 一个能用云电脑的 Grok Bot
- 不需要任何商店账号

## 步骤

1. 让 Bot 写一个只发 GET 请求的小脚本，读 Epic 促销接口和 GOG 商品目录接口。
2. 按类型分行：限时免费领取、Demo、本来就免费、预告、要订阅才免费。
3. 把接口里的 UTC 时间换成你的时区。
4. 每次结果存一份清单，下次只报新增；没有新的就回一句“无变化”。
5. 手动跑一次看过没问题，再存成技能，建一个每周跑一两次的 Routine。

## 提示词

```text
帮我做一个免费游戏侦察技能：
1. 只用 Epic 公开促销接口和 GOG 公开商品目录接口，别的消息只当线索，每条回官方核实。
2. 每条标清类型：限时免费领取、Demo、本来就免费、预告、要订阅才免费；接口里没有的评分简介不要补。
3. 截止时间换成 {{你的时区}}。
4. 和上一轮比，只报新出现的；没有就回一句“无变化”。
5. 只给商店页链接，不登录、不领取、不付款；遇到登录或验证码就停下告诉我。
```

## 产出

每周一条短消息：几个限时免费领取（含截止时间和链接）、下周预告，或者一句“无变化”。

## 注意事项

- 商店页面会拦截脚本访问，用接口拿数据，链接留给自己在浏览器里打开。
- GOG 的免费商品一大半是 Demo，一定要单独列。
- 跑得太勤只会浪费额度，Epic 一般每周换一次。
