# 实跑结果打成离线 HTML 报告

- **适合**：要把多段终端输出交给同事、又不好塞一堆散文件的人
- **详细教程**：[打成离线 HTML 报告](https://grokguide.si/tutorials/html-report-pack)

## 场景

一次实跑留下 cover 说明、多段 log、检查表。邮件里贴纯文本难读，打包成单页 HTML 更清楚。

## 步骤

1. 收集标题、摘要、各 section 的预格式化文本。
2. 生成单文件 HTML（内联基础样式），自检 h1=1、h2 数量。
3. 不外链登录态资源；图片用相对路径或可选嵌入。

## 提示词

```text
把这次实跑的几段终端输出打成一个离线 HTML 报告：一个 h1、若干 h2 小节，代码块保留等宽。
生成后告诉我文件大小和 h1/h2 数量。材料：……
```

## 产出

单页 HTML。样例约 3.6KB，h1=1、h2=5。

## 注意事项

- 报告里不要塞密钥全文。
- 给读屏用户：标题层级要干净，别用纯 div 冒充标题。
