# 少而精小队：自建 Skill + 语音复述验收

- **适合**：Bot 越建越多却不好管，想照官方负责人 poteto 的短指南收成几只好用的人
- **详细教程**：[grokguide.si/tutorials/lean-team-skill](https://grokguide.si/tutorials/lean-team-skill)
- **思路来源**：[lauren（@poteto）的建队短指南](https://x.com/poteto/status/2116576229319233596)

## 场景

岗位堆了一堆，同一套做法反复口授，语音交代完 Bot 却听偏了。

## 准备

- 可选：从模板市场加 [Dr Eggbot](https://x.ai/bot/_jOdbfkB16zxu7MRcmReE) 帮你设计 Bot
- 一份精简花名册（几只好用的，而不是几十个半成品）
- 私有仓库或共享文件夹用来存 skill（可选）

## 步骤

1. 加一只设计向 Bot（或 Dr Eggbot）：专门帮你界定岗位，不替你堆数量。
2. 花名册只留少而精：每只写清管什么、不管什么；同一职责不建第二只。
3. 边教边沉淀：同一套做法讲到第二遍，就让该 Bot 自己写成 skill；需要长期保留就推进私有仓。
4. 接齐连接器和 Vault：能让 Bot 自己读、自己登的，就别再复制粘贴。
5. 像带实习生：先介绍你是谁、日常怎么干活，再问它怎么帮你自动化。
6. 语音脑暴后强制复述：让它「用自己的话复述」，关键点对齐才动手；外发仍等你批准。

## 提示词

```text
请按「少而精」帮我收一版小队花名册（最多 4 只，含可选的设计 Bot）：
对每一只写：岗位名、管什么、不管什么、需要哪些连接器。
不要新建 Bot，先交花名册草稿。

另外：我会语音交代一轮。交代结束后，请用自己的话复述关键点（岗位边界、红线、何时写成 skill）。
复述对齐前不要动手；外发、动钱、改生产一律等我批准。
```

同一做法教第二遍时：

```text
这件事我已经教过你两遍。请整理成一张 skill 卡：目标、前提、步骤、怎么检查、不准做的事。
把会变的内容写成 {{占位符}}。先给我看，不要执行；确认后写入 skills/ 并可推进我的私有仓。
```

## 产出

精简花名册 + 待沉淀 skill 清单 + 一次对齐过的复述记录。

## 注意事项

- 少而精优先于堆岗位；花名册比头衔重要。
- 本账号无 cloud agents 时，不要假装派过云端编程 Agent。
- 复述闸门是开工前的硬条件，不是客套。

## 小伟点评

虚构教过日志 8 条：3 条已教 ≥2 次却还没 skill，扫描后点名要沉淀；语音复述五项关键点全过才允许开工。
