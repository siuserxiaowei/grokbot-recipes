# Linux 新版提醒

- **适合**：在 Linux 上用 Grok Bot、内置更新管不到的人
- **详细教程**：[在 Linux 上装 Grok Bot](https://grokguide.si/tutorials/linux-install)

## 场景

Linux 版不会自己升级。让 Bot 每天问一次官方更新接口，有新版才说话，安装留给你。

## 准备

- 知道自己的架构：终端跑 `uname -m`
- 记下本机现在的版本号

## 步骤

1. 把下面的提示词发给 Bot，让它建一条每天一次的 Routine。
2. 点 Test 跑一次，看它有没有读到版本号和 sha256。
3. 有新版时，按它给的官方地址自己下载安装。

## 提示词

```text
帮我建一条 Routine，每天 {{时间}} 跑一次：
1. 查 Grok Bot 官方更新接口里 {{linux-x64 或 linux-arm64}} 的最新版本号和 sha256。
2. 和上次记下的版本号比，一样就什么都别说。
3. 有新版就把 AppImage 下载到你的云电脑，算 sha256，和接口给的比。
4. 用一句话告诉我：新版本号、哈希对没对上、官方下载地址。
5. 不要在我的电脑上执行任何安装命令。
```

## 产出

有新版时一句话：版本号、哈希是否一致、下载地址。没有新版时不打扰。

## 注意事项

- 社区的 Fedora、Arch 包是非官方的，也没有签名；求稳用官方 deb 或 AppImage。
- 手动下载社区包时看清文件名里的版本，同一个 release 里可能挂着上一版。
