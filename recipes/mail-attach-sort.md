# 邮件附件归类：只复制不删

- **适合**：邮箱附件堆成山、发票合同混在一起的人
- **详细教程**：[邮件附件归类](https://grokguide.si/tutorials/mail-attach-sort)

## 场景

发票、合同、截图、乱七八糟的 zip 全在下载目录。直接删除危险，先分桶更稳。

## 步骤

1. 从导出或下载目录收集附件样本（先小批量）。
2. 按扩展名/关键字分到 invoices、contracts、images、other。
3. 同内容哈希进 duplicates；只复制，不动原件。
4. 给你清单：每桶数量、重复对、无法判断项。

## 提示词

```text
帮我把这个附件目录归类：发票、合同、图片、其他；相同内容进 duplicates。
只复制不删原件。先处理我标出的小样本，输出每桶数量和重复清单。
目录：……
```

## 产出

分桶目录 + 重复清单。样例 7 个文件，1 对重复发票。

## 注意事项

- 永远先复制；确认后再由你删原件。
- 加密 PDF / 无扩展名单独列，不猜。
