# 桌面 0.77.0 记忆导入：先草稿再进 Settings

- **适合**：从其他 AI 助手换到 Grok Bot，想搬家偏好与记忆、又要剥掉密钥的人
- **详细教程**：[桌面 0.77.0 记忆导入：先草稿再进 Settings](https://grokguide.si/tutorials/memory-import-pack)

## 场景

导出 JSON → Markdown 草稿 → 剥离 API_KEY/sk- → Settings → Import Memory to Grok Bot；缺项用问答卡片补。

## 准备

- 其他助手导出
- 桌面 Grok Bot 0.75.2+

## 步骤

1. 转换草稿
2. 核对剥离列表
3. Import Memory
4. 问答卡片补洞
