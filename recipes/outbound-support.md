# 海外客服：多语言工单先分流

- **适合**：做海外用户的团队
- **详细教程**：[grokguide.si/playbooks/support-five-jobs](https://grokguide.si/playbooks/support-five-jobs)

## 场景

工单语言多、类型杂，重要的事容易被淹没。

## 准备

- 工单导出（去掉联系方式）
- 一份产品事实卡：功能、政策、常见问题

## 步骤

1. 导入工单时去掉邮箱、电话等个人信息。
2. Bot 输出一张表：语言、类型、优先级、建议处理人。
3. 只给咨询类写回复草稿，按用户的语言写。
4. 付款、安全、法律、投诉一律标“转人工”，不写草稿。
5. 你在客服系统里核对后再发送。
6. 反复改的句子补进事实卡。

## 提示词

```text
请处理 {{工单文件}}：先输出一张表，列出每条工单的语言、类型（问题/需求/咨询/投诉/其他）、优先级。只给咨询类写回复草稿，用用户的语言，只依据这份事实卡：{{事实卡}}，查不到就写“需要人工确认”。涉及付款、退款、账号安全、法律的，标“转人工”，不要写草稿。不要直接发送任何回复。
```

## 产出

一张分流表加一组草稿。

## 注意事项

- 别让 Bot 承诺还没上线的功能。
- 事实卡要定期更新。
