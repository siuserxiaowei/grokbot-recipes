# 技能钉版本：装之前先对 sha256

- **适合**：想装别人写的技能，又怕作者以后改了内容、或者中途被人动了手脚的人
- **详细教程**：[grokguide.si/tutorials/pinned-skills](https://grokguide.si/tutorials/pinned-skills)

## 场景

从 GitHub 装技能很方便，可文件随时会变。给每个技能文件记一个 sha256，再给这份清单本身也记一个；以后装或更新时先对一遍，对不上就不装，并告诉你是哪一个。

## 准备

- 一个想装的技能仓库，最好用某个具体提交的链接，而不是 main
- 作者给的哈希清单，或者你自己第一次核对后生成的清单
- Bot 能用云电脑跑 Python（只用自带库即可）

## 步骤

1. 让 Bot 把技能文件下载到一个临时文件夹，不要直接放进技能目录。
2. 先核对清单本身的 sha256，对不上就整批停下。
3. 逐个文件算 sha256，和清单比；对不上的那个不装，并写明期望值和实际值。
4. 全部对上才复制进技能目录，并记下来源提交和清单哈希。
5. 自己写的技能也照样生成一份清单，存在技能旁边，以后改了能看出来。
6. 更新时重复一遍：换新提交、拿新清单，先看改了什么再装。

## 提示词

```text
帮我按“钉版本”的方式装技能：{技能仓库某个提交的链接}，清单哈希是 {PINS 的 sha256}
1. 先把文件下载到云电脑上的临时文件夹，别直接放进技能目录。
2. 先算清单文件的 sha256，和我给的比，对不上就整批停下告诉我。
3. 再逐个算技能文件的 sha256，和清单比；哪个对不上就不装那个，告诉我期望值、实际值和文件大小。
4. 全部对上才装进技能目录，并记下来源提交和清单哈希。
5. 贴原始输出给我看，不要只说“装好了”。
6. 以后我说“更新技能”时，先列出改了哪些文件，等我点头再装。
```

## 产出

一个只装“哈希对得上”的技能的小脚本、一份写着来源提交和清单哈希的记录，以及你自己技能的哈希清单。

## 注意事项

- 哈希只能证明文件没被改过，不能证明内容本身靠谱，第一次装前还是要读一遍技能写了什么。
- 链接要用具体提交，用 main 的话清单和文件都可能一起变。
- 思路参考 [dallintwatts/grokbot-skills](https://github.com/dallintwatts/grokbot-skills)。
