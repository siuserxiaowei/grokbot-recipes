# 安静检查：没变化只打一行 quiet

- **适合**：巡检 Routine 多数时候没变化、却老刷屏的人
- **详细教程**：[grokguide.si/tutorials/quiet-check](https://grokguide.si/tutorials/quiet-check)

## 场景

每小时盯价格表或文件夹，没变化也来一长串。

## 准备

- 一个要监视的目录或文件列表

## 步骤

1. 用内容哈希做快照，写入状态文件。
2. 和上次比：added / removed / changed。
3. 全空：只打印 `quiet: no change`，exit=0。
4. 有变化：列出文件名，exit=1；Bot 再决定要不要读内容。
5. 先跑三次：建基线、无变化、改一处。

## 提示词

```text
帮我做一个安静巡检脚本，监视目录：{{路径}}
1. 只读；用内容哈希和上次状态比。
2. 没变化：只打印一行 quiet: no change，exit=0。
3. 有变化：打印 added/removed/changed，exit=1；不要自动改文件、不要发消息。
4. 先跑三次给我看：建基线、无变化、我改一处之后。
5. 确认后挂 Routine，先一小时一次；发送、删除照旧要我点头。
```

## 产出

安静退出的小脚本、状态文件、一条低频 Routine。

## 注意事项

- 承接「脚本先跑」：固定的活交给脚本，Bot 只看一行结果。
- 大文件可只哈希前 N 字节加文件大小，规则要写进状态版本号。
