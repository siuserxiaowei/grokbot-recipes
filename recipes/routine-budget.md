# 额度体检：先停、分级、逐条重开

- **适合**：开了很多 Routine 的人
- **详细教程**：[grokguide.si/guide/ch11](https://grokguide.si/guide/ch11)

## 场景

额度掉得比预期快，又说不清是哪条 Routine 在烧。

## 准备

- Routine 列表的访问权限
- 一份你认为必须保留的任务清单

## 步骤

1. 让 Bot 列出所有 Routine：名称、频率、上次运行、每次大概做什么。
2. 全部暂停，不删除。
3. 按“每天必须 / 每周就够 / 可以不要”分三级。
4. 先只开第一级，跑满一周看用量，再逐条加回。

## 提示词

```text
请列出我所有的 Routine，每条写清：名称、运行频率、上次运行时间、每次做什么。然后把它们全部暂停（不要删除）。按“每天必须 / 每周就够 / 可以不要”分级，给出理由。先只帮我重开第一级，其余等我确认。
```

## 产出

一张三列表格，加一句建议的重开顺序。

## 注意事项

- 暂停和删除不一样，删除后配置找不回。
- 频率改低往往比关掉更划算。
