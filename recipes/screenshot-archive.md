# 网页截图按日期归档

- **适合**：要盯公开页有没有改、又不要登录爬站的人
- **详细教程**：[网页截图按日期归档](https://grokguide.si/tutorials/screenshot-archive)

## 场景

竞品首页、自己的落地页、官方 Changelog，隔几天想对比一眼。整站爬虫重且容易踩登录墙。

## 步骤

1. 列 URL 清单（只要公开页）。
2. 无头浏览器打开首屏，存 PNG + 当日目录。
3. 写 SHA256 清单；HTTP 非 200（如 403）也如实记，不造假图。
4. 下次跑完用清单 diff，只标变化项。

## 提示词

```text
帮我把这些公开页的首屏按日期截图归档，目录带日期，附 SHA256 清单。
遇到 403/登录墙如实记失败，不要用旧图顶替。先跑我给你的 2～3 个 URL。
URL：……
```

## 产出

日期目录 + manifest。我们实跑：grokguide 首页与 Fedora 页 200；x.ai changelog 403 如实进清单。

## 注意事项

- 只盯公开页；登录墙交给你本机浏览器。
- 403 是教学点，不是缺陷隐瞒。
