# 手机建站六棒：主 Bot 串岗，每棒你点头

- **适合**：想用多 Bot 从零到 1 做网站，又怕跳棒、自合 PR、编数字、密钥进聊天的人
- **详细教程**：[grokguide.si/tutorials/six-bar-site](https://grokguide.si/tutorials/six-bar-site)
- **思路来源**：[KinGao476942 长文 · 如何用 Grok Bot 从零到 1 开发上线一个网站](https://x.com/KinGao476942/status/2117853896580456514)（2026-11-04）。我们**没有**照搬岗位 JD 与案例站细节，只提炼闸门与调度节奏。

## 场景

手机上跟云端 Bot 对话就能把网站推到「写好先放着」；但若主 Bot 自己写代码、跳过测试呈合、CI 绿就催合，就会把额度烧在返工上。需要六棒顺序 + 老板点头才上线。

## 准备

- 主 Bot + 六个岗位席位（调研 / 产品 / 设计 / 开发 / 测试 / 司令部），日常只跟主 Bot 说话
- GitHub 仓库；密钥放安全保管位置，不进聊天、不进仓库明文
- 第一版「必须有 / 明确不做」写清楚；不编搜索量、收入、口碑

## 步骤

1. 建好人设后，只对主 Bot 说一句话开流水线：调研 → 产品 → 设计 → 开发 → 测试 → 司令部。
2. 每棒交付物出来就停住等你确认；不许跳棒。
3. 开发开 PR 并保持 OPEN；先写单元测试再写实现。
4. 测试必须用**另一个 AI**；Fail 退回开发，不过不得送司令部。
5. 司令部只呈合材料，默认不自动 merge；CI 绿 ≠ 可合。
6. 只有你当面回「准」之后，才允许合 PR / 上线。

## 提示词

```text
你是项目总协调（主 Bot）。请按「调研 → 产品 → 设计 → 开发 → 测试 → 司令部」六棒串岗，帮我从零到 1 做一个真能用的小站。日常我只跟你说话。

【第一版必须有 / 明确不做】
必须有：……
明确不做：……
禁区：假搜索量、假口碑、保证爆款、蹭官方身份；密钥不进聊天/仓库；禁止任何 Bot 自合 PR / 自放上网。

1）调研简报（只写方向与摘记，禁止编数字）→ 停，等我确认
2）PRD（含验收标准与明确不做）→ 停，等我签字
3）关键页原型图 + 设计说明 → 停，等我点头
4）架构方案先确认，再按模块 TDD 开发；PR 保持 OPEN
5）另一个 AI 测试；Fail 退回；不过不得送司令部
6）司令部呈合说明；默认不自动 merge
7）只有我当面回「准」后才合 PR / 上线

你自己不写业务代码、不合 PR、不删文件。每棒用大白话汇报：谁在干、交付了什么、要我确认什么。
```

## 产出

可调度的六棒节奏 + 闸门话术 + （可选）虚构六事件巡检 ASSERT_OK。

## 注意事项

- 岗位 JD 是建人设用的，不是每天逐个开聊；日常只跟主 Bot。
- 本配方不替你建真实多 Bot，也不宣称跑过真实建站上线。
- 上游长文有完整案例与 JD；本页只保留闸门，细节请回原文。

## 小伟点评

虚构六闸门：等确认、测试未过拦截、自合拦截、跳棒拦截、编数字拦截、点头才上线；ASSERT_OK。
