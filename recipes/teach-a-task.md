# 教会一次：把手动操作变成技能

- **适合**：有一件事每周都要手动做一遍的人
- **详细教程**：[grokguide.si/qa/teach-skill](https://grokguide.si/qa/teach-skill)

## 场景

每次都重新解释一遍步骤，Bot 做法还不一样。

## 准备

- 一次完整的手动操作（录屏或步骤记录）
- 一个低风险的测试样例

## 步骤

1. 你完整做一遍，Bot 只看不动手。
2. 让 Bot 写成技能卡：目标、前提、步骤、怎么检查、出错怎么办。
3. 你删掉真实账号和网址，补上“不准做的事”。
4. 用假数据空跑一遍，只出计划不真改。
5. 挑一个低风险的真实样例跑一次，出错就改技能卡。
6. 以后同类任务先读技能卡再动手。

## 提示词

```text
刚才我演示了 {{任务名称}}。请整理成一张技能卡：目标、需要提前准备什么、逐步操作、每步怎么检查做对了、出错时怎么停下并告诉我。把所有会变的内容写成 {{占位符}}。最后单独列一节“不准做的事”。先给我看，不要执行。
```

## 产出

一张可审阅的技能卡。

## 注意事项

- 技能卡和对话冲突时，以技能卡和你当场的指示为准。
- 别把一次性的特殊情况写进通用技能。
