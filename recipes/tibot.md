# tibot：盯自己的提及与关键词，从不代发

- **适合**：在 X 上有账号、想及时看到别人提你或谈你关键词、又不想让 Bot 替你发帖或擅自拉黑的人
- **详细教程**：[tibot：提及与关键词摘要](https://grokguide.si/tutorials/tibot)

## 场景

公开雷达扫行业话题，传播分工作台盯别人的爆款；你还缺一块——**关于你自己的提及与关键词**（没 @ 你的也会抓）。tibot 模板每天（或每小时）给一份排好序的短摘要：过滤垃圾、翻译非英文帖；可选在你明确说「是」之后再拉黑喷子。它从不替你发帖。

## 准备

- 能导入第三方模板的 Grok Bot 账号
- 模板链接：https://x.ai/bot/xZ4wRvomWqzCXnyYFr7i3（作者 [@poteto](https://x.com/poteto) 发布帖）
- 写清：你的 handle、要盯的关键词、摘要频率（每天 / 每小时）、时区

## 步骤

1. 打开模板链接，点导入；核对 Bot 说明里「从不替你发帖」。
2. 告诉 Bot 你的 `@handle`、关键词列表、摘要时间（例如每天 Asia/Shanghai 09:00）。
3. **写死硬规矩**：不自动发帖、不自动回复、不自动点赞；拉黑/静音只在你明确回复「是」之后执行。
4. 先要一份**虚构样例摘要**核对格式（优先级、原文链接、是否需你出手），再开定时。
5. 日常只读摘要；要互动或发帖，一律你自己来。

## 提示词

```text
你是我的 tibot 风格「提及与关键词摘要」Bot。只盯和我有关的帖，不代发。

硬规矩：
1. 抓取：@{{handle}} 的提及，以及含这些关键词、即便没 @ 我的公开帖：{{keywords}}。
2. 过滤垃圾、抽奖、明显广告；非英文帖给出中文一句话摘要并附原文链接。
3. 默认每天 {{time}}（时区 {{timezone}}）出一份短摘要，按优先级排序；没有值得看的只记一行「今天没有更新」，不要刷存在感。
4. 绝不代发、代回复、代点赞、代转发；任何对外动作先问我。
5. 拉黑 / 静音：只在我明确回复「是」之后执行；默认只建议，不要自动动手。
6. 和「公开话题雷达」「传播分工作台」分开：你只盯关于我的提及与关键词，不扫行业大盘，不写传播分草稿。

请先问我：handle、关键词、摘要频率与时间。然后给一页装机核对清单和一份虚构样例摘要（标注虚构），不要自动改我现有配置。
```

## 产出

每天（或每小时）一份短摘要；可选「建议拉黑」清单等你确认。无内容时安静。

## 注意事项

- **和 X 雷达不同**：雷达扫公开关键词/账号大盘；tibot 盯的是**关于你**的提及与关键词。
- **和传播分工作台不同**：传播分写改写草稿并刷新你的 Pages；tibot 只给摘要，不写发帖草稿。
- 自动拉黑容易误伤；默认关掉，改为「建议 → 你回是 → 再执行」。
- 灵感来自 [@poteto 的 tibot 模板](https://x.ai/bot/xZ4wRvomWqzCXnyYFr7i3)；步骤与中文提示词由我们改写，没有照搬原文。
