# 完成前验证闸门：不过禁止标 done

- **适合**：Bot 常说「好了」却缺文件、数字对不上的人
- **详细教程**：[grokguide.si/tutorials/verify-gate](https://grokguide.si/tutorials/verify-gate)

## 场景

交活前缺校验和、摘要没标明样例、或者夹带疑似密钥。

## 准备

- 产物目录和必填文件清单

## 步骤

1. 检查必填文件存在且非空。
2. 按 checksums.sha256 核对内容。
3. 摘要须标明样例或来源。
4. 扫描疑似密钥形态，只报告不删除。
5. 任一项失败禁止标 done。

## 提示词

```text
交活前请跑验证闸门，产物目录：{{路径}}
必查：
1. 这些文件存在且非空：{{文件列表}}
2. checksums.sha256 与文件内容一致
3. 摘要里标明样例或来源
4. 正文未出现疑似密钥形态
任一项失败就禁止标 done，只报告，不要自动改产物。
```

## 产出

一份 PASS/FAIL 报告；全过才能标完成。

## 注意事项

- 密钥扫描可能误伤演示字符串：疑似就 FAIL，由人判断。
- 和「文件交付」教程一起用：先过闸门再交回。
